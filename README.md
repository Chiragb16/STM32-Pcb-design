STM32 Clone Board

This repository contains a custom STM32-based clone board supporting communication interfaces like UART, I2C, and SPI. It is designed for easy integration with sensors and peripherals, providing a simple platform for embedded development.

## Features
- STM32 microcontroller (CubeMX-compatible)
- I2C, SPI, and UART communication
- USB-to-UART programming interface
- 3.3 V logic with optional 5 V input
- Compact PCB layout for quick prototyping

## Development
Projects and peripheral configurations are generated using STM32CubeMX and built with STM32CubeIDE.
